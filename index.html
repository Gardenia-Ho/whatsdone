常见问题

收不到注册验证码怎么办？
  • 先看看垃圾邮件或广告邮件文件夹；
  • 确认邮箱地址没有拼错；
  • 等一分钟左右再重新发送。

如果还是收不到，请发邮件告诉我们你注册用的邮箱。

忘记密码了怎么办？

在登录页点「忘记密码？」，输入注册邮箱，用收到的验证码设置新密码即可。

换手机或用多台设备，数据会同步吗？

会。任务、日记、目标、聊天记录和个人资料会跟着账号同步到云端，在新设备上用同一个账号登录就能看到。

怎么备份数据？

在「我的 → 数据管理 → 导出数据到本地」可以导出一份备份文件，需要时用「从手机中导入数据」恢复。

收不到每日提醒？
  • 到 iPhone 的「设置 → 通知 → 干啥了」，打开「允许通知」；
  • 在 App 的「规划助理 → 对话框设置 → 提醒时间」里确认已设置提醒时间。
怎么注销账号？

在「我的 → 账号安全 → 注销账号」中操作。注销后，账号和云端同步的数据会被永久删除，无法恢复。建议注销前先导出备份。

FAQ

I didn’t get the sign-up code.
  • Check your spam or junk folder.
  • Make sure the email address is spelled correctly.
  • Wait about a minute, then request a new code.

Still nothing? Email us the address you signed up with.

I forgot my password.

On the sign-in screen, tap “Forgot password?”, enter your email, and use the code we send you to set a new password.

Does my data sync across devices?

Yes. Your tasks, journal, goals, chat history and profile sync with your account. Sign in with the same account on a new device and everything comes back.

How do I back up my data?

Go to Me → Data Management → Export Data to Device to save a backup file. Use Import Data from Device to restore it.

I’m not getting the daily reminder.
  • Open iPhone Settings → Notifications → What’s Done and turn on Allow Notifications.
  • In the app, check Planning Assistant → Chat Settings → Reminder Time.
How do I delete my account?

Go to Me → Security → Delete Account. Your account and synced data are permanently deleted and can’t be recovered, so export a backup first if you want one.
